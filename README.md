# Schulddienstverlening Register

**Een open source domeinregister voor schulddienstverlening, gebaseerd op het GGM-informatiemodel.**

## Status

🚀 In Development | Versie: 0.1.0

## Wat is dit?

Een gestandaardiseerde, beveiligde API en database voor het registreren en beheren van 
schulddienstverlening in Nederland. Bedoeld voor:

- Gemeenten
- Schuldhulpverleners
- Maatschappelijke organisaties
- Burgers (self-service)

## Nalevingsstandaarden

✅ **Nederlandse API Design Rules** (v3.0)
✅ **Common Ground Principes**

✅ **BIO2** (informatiebeveiligingskader)
✅ **ISO 27001** (informatiebeveiliging)

## Snelle start

```bash
git clone https://github.com/vng-realisatie/schulddienstverlening-register
cd schulddienstverlening-register
docker-compose up
curl http://localhost:8000/api/v1/schulddossiers
```
