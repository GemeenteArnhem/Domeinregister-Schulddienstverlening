## BIO2 Compliance

BIO2 is de **Nederlandse standaard voor informatiebeveiliging in de publieke sector**.

### BIO2 Maatregelen

#### Organisatorisch

✅ **O1: Informatiebeveiligingsbeleid**
- Governance document (dit document)
- Jaarlijkse review
- Ondertekend door directie

✅ **O2: Risicoanalyse**
- ISOIEC 27005 risk assessment
- Jaarlijkse update
- Risk register beheerd door CISO

✅ **O3: Personeelsvoorbereiding**
- Security awareness training (verplicht jaarlijks)
- NDA signing
- Background checks (voor admin staff)

✅ **O4: Incidentmanagement**
- Incident response plan
- 24/7 escalatie procedure
- Post-incident review

#### Technisch

✅ **T1: Toegangscontrole**
- MFA verplicht (TOTP/SMS)
- RBAC op basis van rollen
- Least privilege principle

✅ **T2: Versleuteling**
- AES-256 at rest
- TLS 1.3 in transit
- Separate encryption keys per customer (optioneel)

✅ **T3: Audit trail**
- Immutable logging van alle actions
- Log integriteit geverifieerd
- 7 jaren retention

✅ **T4: Monitoring**
- SIEM (Security Information & Event Management)
- Real-time alerting
- Centralized log aggregation

✅ **T5: Business continuity**
- RTO: 4 uur (Production outage)
- RPO: 1 uur (Data loss)
- Backups: Dagelijks, off-site, versleuteld

#### Juridisch

✅ **J1: Contractueel**
- Data Processing Agreements (DPA)
- Service Level Agreements (SLA)
- Confidentiality clauses

✅ **J2: Compliance**
- GDPR compliance audit (jaarlijks)
- BIO2 self-assessment (jaarlijks)
- External audit (om de 2 jaar)

## Privacy Impact Assessment (PIA)

### Data Processing Summary

| Categorie | Data Type | Verwerking | Rechtsgrondslag |
|-----------|-----------|-----------|-----------------|
| Burgers | BSN, naam, adres | Schulddossier beheer | Publieke taak (Faillissementswet) |
| Schuldhulpverleners | KvK, contactgegevens | Registratie & monitoring | Contract |
| Gemeente medewerkers | Email, IP address | Logging van system access | Employment contract |

### GDPR Rights Implemented

✅ **Right to access**: `GET /burgers/{id}/schulddossier`
✅ **Right to rectification**: `PUT /burgers/{id}/contactgegevens`
✅ **Right to erasure**: `DELETE /burgers/{id}` (cascade delete dossiers)
✅ **Right to restrict**: Row-level security voor confidential records
✅ **Right to data portability**: `GET /export/schulddossier.json` (all personal data)
✅ **Right to object**: Opt-out from notifications

### Data Minimization

- Burgers: Enkel BSN + contact info (rest via referentie)
- Instellingen: Enkel statutaire info (rest via KvK API)
- Logs: Maskeer BSN, creditcardnummers, etc.
